# 📝 Blog Management System

A professional Blog Management System developed using **PHP** and **MySQL** as part of the ApexPlanet Web Development Internship.

## 🚀 Features

- User Registration
- User Login
- Dashboard
- Create Post
- View Posts
- Edit Posts
- Delete Posts (Admin Only)
- Search Posts
- Pagination
- Password Hashing
- Prepared Statements
- Session Management
- Role-Based Access Control
- Responsive User Interface
